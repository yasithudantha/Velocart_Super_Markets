# Velocart System

Welcome to Velocart! This is a comprehensive e-commerce platform built with ASP.NET Core, React, and Flutter.

## Current Stage: Basic Features (Development)
In this stage, our team has integrated the core components of the system. 
- **Catalog & Storefront:** Initialized
- **Auth & Cart:** Scaffolding added
- **Loyalty & Promotions:** Basic service logic
- **Orders & Disputes:** Base controllers

*Note: There are currently known issues with discount calculations and authentication validation that will be addressed in future sprints.*
